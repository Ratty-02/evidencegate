# Demo script (under 3 minutes)

**0:00–0:20: The problem.** "Merchants answer payment disputes by hand, and one wrong date can sink a case. A model can write the response, but nothing should go out unchecked."

**0:20–0:50: The case board.** Show the lanes. Point at a blocked case and say what blocked it.

**0:50–1:30: One case, end to end.** Open a case. Show the five-stage pipeline, the claims with their source records, and the uncovered-sentence warning. Edit nothing; show that approval is disabled.

**1:30–2:00: Approve a good case.** Slide to approve. Show the approval record and that it survives a refresh.

**2:00–2:30: Measured, not claimed.** Show the evaluation: injected errors caught, clean drafts passed, routing correct. Say these are labeled cases the author designed.

**2:30–3:00: Limits, stated plainly.** PayPal's sandbox has no disputes for this account yet, so the case board shows mock data. Real reads work, and writes are tested offline against PayPal's documented shapes. Tracking records come from the merchant.
