How it works

Three steps. Nothing skips the gate.

1

Read the dispute

Pull the dispute, transaction, and tracking records. Every fact the response can use comes from these.

2

Draft with AI

The model drafts a response where each sentence is tied to a source record. Malformed output is rejected.

3

Gate, then approve

Rules and grounding checks run first. Blocked drafts cannot be approved. You make the final call.

What the gate checks

Four checks before anything is sent.

01

Dispute status

Evidence is only sent while the dispute is still open and PayPal's evidence link is present.

02

File rules

Accepted types and size limits, checked before upload, so submissions don't fail late.

03

Claim grounding

Every claim must cite a real record, with the field and value matching exactly.

04

Sentence coverage

Any sentence in the response that no claim supports is flagged and blocks submission.
